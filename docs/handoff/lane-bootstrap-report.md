# Lane bootstrap report

**Integration dependency:** `ravel-bootstrap` uses these loader and host-api APIs, which the loader/SDK lanes are
adding:

- `ravel_loader::InterceptRefused`
- `LifecycleMachine::save_access` (renamed from `request_save`)
- `Delivery::failed_by`
- `Round::failed_by`
- `open_saved_data` handling of failed owners and panic guards

Until those land, `ravel-bootstrap` does not compile in this worktree. Every remaining error is one of these missing
symbols (the gate log).

  redacted `env.throw`.
- **crates/ravel-build/src/tests.rs:** generated driver uses `write_world_pack(&resources, &world)`; contract assertions
  for the redacted throw, boolean ABI and exact switch.

  removed.
- **jvm/bootstrap/dev/ravel/jvm/Agent.java, jvm/harness/initialization/dev/ravel/jvm/Hook.java:** profiling boolean
  passed to initialize.
- **crates/ravel-host-runtime/{Cargo.toml,src/lib.rs}:** single install, game directory, profiling flag, redacted
  `LaunchError`.
- **tests/conformance/{Cargo.toml,tests/integration/content_declarations.rs}:** migrated `write_world_pack` caller.
- **docs/guide/limits.md:** command-authority gap (#2).
- **Requested of Main/other lanes:** bounded `PreWorldReport` notes and a redacting host panic hook (Main accepted); SDK
  boundary-case crate names (#5); dependency-rules.md prose (Tooling).
