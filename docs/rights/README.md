# Rights and provenance

This directory contains public policy, schema guidance, and blank templates
only. Counterpart-specific research, permission correspondence, publication
status, and any source-derived or rights-sensitive notes belong in the private
compatibility workspace.

Every publication candidate must have a record conforming to
[`schemas/provenance.schema.json`](../../schemas/provenance.schema.json). Review
code, observable behaviour, assets, names, branding, quests, scripts,
permissions, licences, notices, and attribution as separate surfaces.
Unresolved or prohibited rights block publication.

Compatible open-source inputs may inform a reimplementation only under their
licence terms.
Closed, All Rights Reserved, or unclear implementations require an independent
behaviour-only specification unless explicit permission or a compatible licence
allows more. Translating an implementation into Rust does not by itself resolve
derivative-work or asset rights.
