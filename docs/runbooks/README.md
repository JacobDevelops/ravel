# Runbooks

Runbooks capture reproducible operator procedures. M0 fills in exact commands,
versions, hashes, numeric workload definitions, and expected outputs before a
runbook can support milestone evidence.

- [`prism-launch.md`](prism-launch.md) — Prism-owned instance and launch handoff.
- [`baseline-capture.md`](baseline-capture.md) — canonical performance capture.
- [`evidence-admission.md`](evidence-admission.md) — sanitization and manifest
  admission.
- [`recovery.md`](recovery.md) — fail-closed world and process recovery.
- [`release.md`](release.md) — local release-candidate checks; publication is a
  later, separately authorized operation.
