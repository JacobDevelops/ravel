# Runbooks

Runbooks capture reproducible operator procedures. Exact commands, versions,
hashes, numeric workload definitions, and expected outputs must be filled in
before a runbook can support milestone evidence.

- [`prism-launch.md`](prism-launch.md) — Prism-owned instance and launch handoff.
- [`baseline-capture.md`](baseline-capture.md) — canonical performance capture.
- [`evidence-admission.md`](evidence-admission.md) — sanitization and manifest
  admission.
- [`recovery.md`](recovery.md) — fail-closed world and process recovery.
- [`release.md`](release.md) — local release-candidate checks.

Publisher signing, publisher identity, moderation, distribution, and remote publication
require a separately approved plan.
