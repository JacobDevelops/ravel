## 1. What this entry is

A machine-power add-on whose behavioural content is one consumable capacitor item
(**read**). Unlike the base fixed-level capacitors, it has durability and takes
one point of damage each time a machine uses it; its power "level" scales with an
efficiency enchantment (**read**).

## 2. The numbers

- **Durability**: 512 uses (**read**).
- **Level**: `3.5 + efficiency_level * 0.5` (**read** — base 3.5, plus half a
  level per efficiency rank).
- Each machine use consumes one durability point; at zero the item is broken and
  no longer usable (**read**).
- It accepts the efficiency enchantment specifically, in addition to whatever the
  base capacitor allows (**read**).

## 3. What a counterpart implements

The level formula, the durability counter with per-use decrement and a broken
predicate, and the enchantment-support check.

## 4. What this specification does not specify

- **Item registration, machine wiring, and the capacitor-data cache**: host
  concerns (the cache is an optimisation, not behaviour).
- **Coverage.** Read in full: the durability, level formula, and enchantment
  support. Everything else: listed, not read.
