## 1. What this entry is

A terrain-overhaul entry that is almost entirely a worldgen datapack; its code
component is minimal (**read**). The only behaviour is a small configuration
system that conditionally disables certain worldgen features through resource
conditions (**read**).

## 2. The one behaviour

Given a feature identifier and the configuration, decide whether that feature's
resource condition is met — i.e. whether the feature should be generated
(**read**). Toggles default such that features are enabled unless explicitly
switched off (**inferred** — the config is a set of opt-out booleans).

## 3. What a counterpart implements

The configuration record and the condition-met predicate. The worldgen itself is
data (JSON biome/structure/noise settings) and is not code.

## 4. What this specification does not specify

- **The worldgen data**: biomes, structures, noise — a datapack, not prose.
- **Coverage.** Read in full: the config toggle and its condition check.
  Everything else: data, not read.
