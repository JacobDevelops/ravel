## 1. What this entry is

A memory-optimisation entry. The portable core is a compact block-state property
lookup: instead of a hash map from property to value, each property is assigned an
offset and a value count, and a block state is a single integer index that packs
all property values (**read**).

## 2. The packing scheme

- Each property occupies a contiguous "digit" of a mixed-radix integer: it has an
  offset divisor and a value count, so its value is `(index / divisor) %
  value_count` (**read**).
- The total number of states is the product of the value counts (**read**).
- Extracting a property's value from a state index, and producing a new state
  index with one property changed, are both pure integer arithmetic on the
  mixed-radix encoding (**read**).

## 3. What a counterpart implements

The property descriptor (offset divisor, value count), the extract and with-value
operations, the total-states product, and a builder that assigns offsets from an
ordered property list, plus name→index lookup.

## 4. What this specification does not specify

- **Coverage.** Read in full: the mixed-radix encode/decode and the builder.
  The dedup optimisation: named, not specified.
