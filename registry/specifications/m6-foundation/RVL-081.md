## 1. What this entry is

A configuration library. Its portable core is JSON-backed config field validation
and a small runtime recipe constructor (**read**). Automatic GUI generation is a
client concern.

## 2. Field validation

A config field declares a type (boolean, integer, floating, string, and similar),
and validating a JSON value against a field returns a typed result: valid,
type-mismatch, or out-of-range (**read**).

## 3. Runtime recipe construction

Helpers build recipe descriptions at runtime — a shapeless recipe (a list of
ingredient ids, a result id and count) and a smelting recipe (an input, a result,
a cooking time, and an experience value) (**read**).

## 4. What a counterpart implements

The field descriptor and type enum, the validate-field function returning a
typed result, and the shapeless/smelting runtime-recipe constructors.

## 5. What this specification does not specify

- **The config GUI generation**: client concern.
- **File I/O and the on-disk format**: host concern.
- **Coverage.** Read in full: the field types, validation outcomes, and the two
  recipe constructors. GUI: named, not specified.
