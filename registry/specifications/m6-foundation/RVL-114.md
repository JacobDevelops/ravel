## 1. What this entry is

A library providing text search/filter for other entries' GUIs (**read**). The
portable core is query parsing and matching; the widgets themselves are client
concerns.

## 2. Query and matching

- A query is parsed into whitespace-separated tokens; an empty query matches
  everything (**read**).
- Match-all: a candidate matches when it contains every token (AND) (**read**).
- Match-any: a candidate matches when it contains at least one token (OR)
  (**read**).
- Matching is case-insensitive substring containment per token (**inferred** —
  the fuzzy layer reduces to substring containment at this boundary; the
  highlight/history features are presentation).
- A generic filter applies a query's match-all over an iterable, projecting each
  item to its searchable text.

## 3. What a counterpart implements

The query type with token parsing, `matches` (all) and `matches_any` (any), and
the generic filter.

## 4. What this specification does not specify

- **Widgets, token highlighting, and search history**: client presentation.
- **Coverage.** Read in full: parse and the two match modes. Presentation:
  named, not specified.
