## 1. What this entry is

A tool that auto-lays a run between two clicked block positions along an axis-
aligned L-shaped route (**read**). The portable core is the path generator
(**read**).

## 2. The path

- A per-axis step direction is the sign of the delta: `+1`, `-1`, or `0` when the
  delta is zero (**read**).
- The route walks from start to end axis by axis — first vertical, then the two
  horizontal axes in a fixed order, with a mirror flag swapping which horizontal
  axis goes first (**read**).
- The result is the ordered list of every block position the run occupies,
  de-duplicated, always including the end point (**read** — the traversal order
  and the guaranteed inclusion of the end are load-bearing and reproduced).

## 3. What a counterpart implements

The block-position type, the sign-step function, and the Manhattan path generator
with the mirror option.

## 4. What this specification does not specify

- **Placing the actual blocks, inventory cost, and the tool item**: host
  concerns.
- **Coverage.** Read in full: the direction step and the traversal order.
  Everything else: listed, not read.
