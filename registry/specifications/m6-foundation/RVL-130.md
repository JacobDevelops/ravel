## 1. What this entry is

A crafting optimisation that caches the last matched crafting-grid recipe and only
re-queries when the grid contents change (**read**). It also suppresses the
recipe-unlock notification (**read**).

## 2. The cache

- A grid state is captured from the ordered slot contents; two states are equal
  when their slot contents are equal, and a state can be empty (**read**).
- A lookup against the cache returns a hit (the cached recipe id) when the current
  grid equals the cached grid, otherwise a miss (**read**).
- Recording a match stores the grid and its recipe id; recording an empty grid
  stores the empty result; invalidation clears the cache (**read**).

## 3. What a counterpart implements

The grid-state value (capture, equality, empty), and the cache with get / record-
match / record-empty / invalidate.

## 4. What this specification does not specify

- **The actual recipe matching** and the notification suppression wiring: host
  concerns (the cache stores an id the host resolves).
- **Coverage.** Read in full: the grid-state equality and the cache operations.
  Everything else: listed, not read.
