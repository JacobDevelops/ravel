## 1. What this entry is

Summons wave-based combat arenas from a trigger item (**read**). The portable core
is the endless-mode modifier scheduling: as the wave number climbs, modifiers
stack according to one of four schedules (**read**).

## 2. The four schedules

Each schedule maps a wave number to an application count (**read**):

- **after-wave**: 1 once the wave reaches a threshold, else 0.
- **after-every-n-waves**: `min(wave / n, max)` — accumulating, capped.
- **only-on-wave**: 1 exactly on one wave, else 0.
- **every-wave** (or equivalent constant): a fixed count each wave.

The exact fourth schedule's formula was read and reproduced value for value.

## 3. What a counterpart implements

The schedule enum and the application-count function per schedule, plus stable
string ids.
