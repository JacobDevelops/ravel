# Sanitized hardware profiles

The Linux profile defines the M9 acceptance host without serial numbers,
usernames, network identifiers, storage paths, or other machine-identifying
data. The Mac profile is reserved for the separate post-Linux-M10 platform
phase.

Before each capture, verify the native host against the relevant profile and
record any stable OS or driver revision in the private raw record. Public
evidence references the profile ID and SHA-256 only.
